# MineCorp

## Backstory

MineCorp is a fictitious company in the world of Minecraft whose role is to turn raw materials into higher value items (products).

## Objectives

. Demonstrate how Neo4j, context graphs, GraphRAG, Neo4j Agent Memory, and an [Enterprise] Knowledge Layer can store complex processes and current world state.
. Create an agent that helps employees (players) navigate the world and answer questions about Minecorp.
. Present the project as a "fun" demonstration of how complex systems and domains can be supported by Neo5j and knowledge layers.

## Deliverables

1. An [Enterprise] Knowledge Layer that describes the state of a Minecraft world / server, the processes/crafting mechanisms, and gives advice based on articles in minecraft.wiki.
    * questions - what is the architecture? what are the build components? how can it show domain, lexical, entity, and agent memory graphs
1. An agent that can answer questions about Minecorp.
    * questions - what tools are required? is the API is just the knowledge graph, or the minecraft api itself? what is the interface (external to minecraft, part of the minecraft chat, both)?
